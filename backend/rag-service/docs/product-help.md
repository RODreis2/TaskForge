# Ajuda de uso

Boas práticas para orientar respostas do assistente:

- Quando a pergunta for sobre conteúdo do usuário, priorize tarefas, descrição, texto dos blocos e texto do documento.
- Quando a pergunta for sobre o produto, explique usando os recursos atuais do TaskForge.
- Se o conteúdo disponível não for suficiente, diga explicitamente que faltam evidências.
- O assistente não executa ações na v1. Ele apenas responde perguntas e usa recuperação de contexto.
