# Visão geral do TaskForge

TaskForge é um workspace para organizar tarefas, pastas e documentos de trabalho em um único fluxo visual.

O produto permite:
- autenticação de usuários
- criação e edição de tasks
- organização em árvore de pastas
- workspace com texto, desenho e imagens
- salvamento contínuo do documento da task

No dashboard, a pessoa usuária consegue:
- navegar pela árvore de contexto
- abrir uma task ativa
- editar o conteúdo textual da task
- desenhar livremente no board
- colar imagens no workspace
